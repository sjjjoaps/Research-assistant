# deep_research

## 工具作用
对复杂研究问题执行五步多阶段研究流程（规划子问题→检索→逐题分析→社区视角→生成报告），输出结构化 Markdown 研究报告。

## 何时使用
- 用户要求"综述""全面分析""系统梳理"某个研究方向
- 问题复杂，需要从多个角度分析，单次检索无法覆盖
- 用户明确说"帮我做深度研究""写一篇研究报告"时
- 需要对比多篇文献并给出系统性结论时

## 何时不使用
- 简单的事实查询（改用 retrieve_knowledge，速度更快）
- 用户只需要一个简短回答时
- 调用前未告知用户该步骤耗时较长时（必须先提示用户）

## 使用约束
- 此工具通常耗时 30~120 秒，调用前必须向用户说明耗时
- max_subquestions 建议 3~4，过多子问题会显著增加耗时
- retriever_mode 默认 mix，适合综述类问题；具体实体密集的问题可选 local
- use_community=True 需要已完成社区检测，否则无额外收益

## 使用示例
### 示例 1：综述类研究
输入：question="稀疏注意力机制的研究现状与主要方法", max_subquestions=3
输出：含研究背景、各子问题分析、综合结论的 Markdown 报告

### 示例 2：比较分析
输入：question="GCN 与 GAT 在图分类任务上的性能对比", retriever_mode="local"
输出：以子问题形式拆解后的对比分析报告
