# get_knowledge_graph_stats

## 工具作用
获取知识图谱的整体统计信息，包括已入库文献数、实体节点数、关系总数、社区数等系统状态指标。

## 何时使用
- 用户询问"知识库有多大""有多少实体""覆盖多少文献"
- 系统状态查询、了解知识图谱整体规模时
- 用户想了解知识库建设情况时

## 何时不使用
- 用户需要具体实体的关系信息（改用 search_by_entity）
- 用户需要文献列表（改用 list_documents）
- 用户需要文献内容（改用 retrieve_knowledge）

## 使用约束
- 此工具无参数，直接调用即可
- 需要 Neo4j 图数据库和 MetadataDatabase 均正常运行，否则返回错误信息
