# save_user_memory

## 工具作用
将用户明确要求持久化的偏好、规则或重要信息写入长期记忆文件，供后续会话调取。

## 何时使用
- 用户说"记住这个偏好"/"以后都这样做"/"记录一下这条规则"时，立即调用
- 用户明确要求持久化某个策略、行为准则或工作习惯时
- 用户要求以后某类问题都用特定方式处理时

## 何时不使用
- 普通对话内容（无需持久化的临时信息）
- 用户没有明确要求记忆的内容
- 单次检索结论、临时问题的答案
- 用户只是描述当前需求，并未要求"记住"时

## 使用约束
- title 应简洁（10-30 字），概括记忆主题
- body 应完整描述规则/偏好内容（支持 Markdown）
- memory_type 仅限：preference（偏好）/ rule（规则）/ note（笔记）
- 保存成功后必须告知用户记忆已写入

## 使用示例
### 示例 1：保存用户偏好
输入：title="回答优先中文输出", body="用户要求所有回答均使用中文，即使问题是英文也要用中文回答。", memory_type="preference"
输出：[记忆已保存] 标题：回答优先中文输出，文件：huida-youxian-zhongwen-shuchu.md

### 示例 2：保存操作规则
输入：title="检索优先使用 hybrid 模式", body="用户明确要求，检索时优先使用 hybrid 模式，而非 auto 自动判断。", memory_type="rule"
输出：[记忆已保存] 标题：检索优先使用 hybrid 模式，文件：jiansuo-youxian-shiyong-hybrid-moshi.md
